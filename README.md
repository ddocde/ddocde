## ✨ Working principles

- **Reproducible over magical** — 环境和流程应当能够重新构建。
- **Explicit over implicit** — 安装、配置、状态与私有数据各有边界。
- **Small systems compound** — 把一次学习变成下一次可以复用的工具。
- **Measure before optimizing** — 先让行为可观察，再谈性能和便利性。
